# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The Agent Memory Mesh project adheres to the **Tier-0 Cyber Sentinel** doctrine of Benni Master OS.

If you discover a vulnerability or data leakage issue:

1. **Do not open a public GitHub issue.**
2. Send an email to `security@bennios.dev` with:
   - Reproduction steps.
   - Proof of Concept (PoC).
   - Impact on tenant boundaries or memory integrity.
3. The security team will respond within 24 hours.
